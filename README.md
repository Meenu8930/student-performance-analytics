# Student Performance Analytics - MCA Internship Project
This project is developed as part of the EWB Internship 2026.

It analyzes student academic performance using Python libraries like Pandas and NumPy to provide meaningful insights from academic data.

## Features
- Calculates average marks of students
- Assigns grades from A+ to D based on performance
- Identifies the topper student
- Calculates subject-wise and department-wise average
- Generates final analyzed report in CSV format

## Tech Stack
- Python 3
- Pandas
- NumPy

## How to Run
pip install pandas numpy
python main.py

## Output
After running main.py, a file named final_report.csv will be generated automatically.
